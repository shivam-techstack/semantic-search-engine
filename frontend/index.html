Document Collection

80 documents across 9 categories: AI, ML, Deep Learning, Data Science, Cybersecurity, Cloud Computing, IR, Computer Networks, General Tech.

🧬

Word2Vec (Semantic)

Skip-gram model trained on the corpus. Each word → 100-dim vector. Documents and queries represented as averaged word vectors.

🔑

TF-IDF (Keyword)

Term Frequency × Inverse Document Frequency. Matches documents by exact query words weighted by rarity across the collection.

🌐

Query Expansion

Before searching, adds semantically similar words to the query using Word2Vec similarity. Bridges the vocabulary gap between query and docs.

🎯

Rocchio Feedback

Runs an initial search, then pushes the query vector toward the top results' centroid (α·query + β·centroid). Re-ranks with improved vector.

📋

Inverted Index

Maps each vocabulary term to its posting list — the set of document IDs that contain that term. Core data structure of all search engines.

🔗

More Like This

Uses a document's own precomputed vector as the query to find the most semantically similar documents in the collection.

📐

Cosine Similarity

Measures the angle between two vectors. Score 1.0 = same direction (identical meaning); 0.0 = orthogonal (unrelated).

System Workflow — All 4 Modes

  • 1Preprocessing (shared)Lowercase → remove punctuation → tokenize → stop word removal → lemmatize.
  • 2Word2Vec TrainingSkip-gram, 100-dim vectors, window 5, 50 epochs on all 80 documents.
  • 3IndexingDocument vectors (averaged Word2Vec), TF-IDF matrix, and Inverted Index are all built once at startup.
  • 4Semantic modeQuery → preprocess → average Word2Vec → cosine similarity vs all doc vectors → rank.
  • 5Keyword modeQuery → preprocess → TF-IDF vector → cosine similarity vs TF-IDF matrix → rank.
  • 6Query Expansion modeQuery tokens → find similar words in W2V vocab → add them → average expanded tokens → cosine similarity → rank.
  • 7Rocchio modeInitial semantic search → centroid of top-3 results → α·query + β·centroid → normalize → re-rank all docs.
